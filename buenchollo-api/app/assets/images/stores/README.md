# Logos de tiendas para la tarjeta de oferta

Un PNG por tienda, con fondo transparente, llamado como la clave de la tienda:
el nombre en minúsculas, sin espacios ni signos (`deal_card.store_key`). Ejemplos:
`amazon.png`, `coolmod.png`, `pccomponentes.png`, `mediamarkt.png`,
`elcorteingles.png`.

La tarjeta recorta los márgenes transparentes y lo encaja en 260 × 56 px dentro de la
pastilla blanca. Mejor un PNG ancho (≥ 400 px) para que se vea nítido. Si una tienda no
tiene logo, la pastilla muestra el punto de color y el nombre.

Origen: `amazon.png` (Wikimedia Commons, logo de Amazon rasterizado a 500 px),
`coolmod.png` (web de Coolmod, `images/logos/logo_coolmod.png`). Marcas de sus
propietarios; se usan solo para identificar la tienda del chollo.
